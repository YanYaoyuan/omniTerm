# omniTerm 桌面交互验收

本清单用于 Electron 桌面应用的真实交互验证。单元测试、打包成功或窗口截图
不能代替终端输入、PTY 生命周期和 Agent 交互验收。每次执行时记录平台、
应用版本或 commit、运行方式（开发 / 安装包）、实际结果和未完成项目。
下表定义验收用例，不代表全部已通过；已完成的检查与未执行项见文末记录。

## 测试准备

- 分别在 macOS、Linux、Windows 原生环境验证；一个平台通过不代表其他平台通过。
- 同时检查开发启动与打包应用，记录 Node / Electron 和操作系统版本。
- 准备一个可操作的本地 shell；执行命令仅使用临时目录和测试文件。
- Agent 测试使用已构建的引擎与测试账号。记录实际可执行路径，区分内置引擎、
  本仓库产物和显式覆盖；不要把登录凭据写入验收记录。
- 远程测试使用受控 SSH/SFTP 服务；串口使用测试设备或可控虚拟串口。
  没有相应环境时标记“未执行”，不能按通过处理。

## 本地终端与窗口

| 用例 | 真实操作 | 通过标准 |
| --- | --- | --- |
| 首次启动 | 启动应用并点击本地终端区域 | 窗口有可见 shell 提示符；按键进入终端，无加载状态卡住或 renderer 错误 |
| 命令输入 | 输入 `pwd` 并回车；Windows PowerShell 同样使用 `pwd` | 显示实际工作目录；光标、回显、换行正常；下一条命令仍可输入 |
| 中英文输入 | 输入 `echo 'omniTerm 中文测试'`；用中文输入法组合后再提交 | 英文即时输入正常；中文候选组合不提前发送或重复；输出不乱码 |
| 复制与粘贴 | 用工具按钮与平台快捷键复制选中文本、粘贴单行测试命令 | 剪贴板权限不阻断正常操作；文本只进入当前焦点终端；无选区复制给出明确反馈 |
| Ctrl+C | 运行 `ping` 或其他持续输出的测试命令，再按 Ctrl+C | 任务中断并回到提示符；终端和应用保持可用 |
| 窗口尺寸 | 缩窄、放大窗口；在调整前后执行宽输出命令 | PTY 行列数随终端可见区域变化；没有永久裁切或光标错位；旧内容可滚动 |
| 字号设置 | 保持窗口尺寸不变，增大和减小字号，再运行全屏终端程序 | xterm 显示与 PTY 行列数同步变化；程序按新网格重绘 |
| 新建标签 | 连续新建至少三个本地标签，各自进入不同目录 | 每个标签是独立 shell，具有独立目录与历史输出 |
| 标签切换 | 在多个标签间反复切换，并让其中一个持续输出 | 返回后内容仍在正确标签；键盘只进入当前终端；隐藏会话不丢输出或重复订阅 |
| 关闭标签 | 关闭正在运行持续输出命令的标签 | 对应会话退出并被清理；其他标签保持正常；已关闭标签不会继续接收输出 |
| 退出 shell | 在 shell 中输入 `exit` | 界面反映会话已退出；不会把按键发送到失效 PTY；可创建新会话 |
| 缺少程序 | 用受控测试配置启动一个不存在的可执行程序 | 显示明确错误；没有永久空白终端；可重试或关闭失败会话 |
| 关闭应用 | 留下多个运行中标签后关闭窗口并退出应用 | 所属 PTY 和子进程被清理；重新打开应用不连接到意外残留进程 |
| 工作区恢复 | 建立两个标签（其一含嵌套分屏、调整比例并重命名，另含一个 SSH 窗格），各窗格 `cd` 到不同目录，退出后重开；再删除其中一个目录后重开 | 本地标签、标签名、分屏比例和目录还原；SSH 窗格未自动重连；不重新执行历史命令；缺失目录回退到默认目录并有提示；关闭“启动时恢复工作区”后重开只得到单个默认标签 |

## Agent 分栏

| 用例 | 真实操作 | 通过标准 |
| --- | --- | --- |
| 打开 Agent | 在有活动本地终端时打开 Agent 分栏 | Agent 在独立 PTY 中启动；本地终端仍可交互；所用引擎路径与配置符合预期 |
| 焦点与按键 | 在 Agent 和普通终端间切换焦点，输入文字、方向键、Tab、Enter、Esc | 按键只到达当前焦点会话；Codex TUI 可选择、编辑和提交；不会同时执行到普通 shell |
| 认证状态 | 在未登录及已登录环境分别启动 | 认证提示或已认证界面可见；认证所需交互不被分栏遮挡或丢失 |
| 执行任务 | 提交读取测试目录并解释文件的低影响任务 | 可见流式输出和任务结束；工具调用或审批可交互；不是静态示例内容 |
| 审批 | 让测试任务触发可控的操作审批，并分别拒绝、允许 | TUI 接收选择；拒绝与允许产生对应行为；界面不默认替用户授权 |
| 取消 | 在运行任务时使用 Agent 的取消按键，并确认后续仍可输入 | Agent 响应取消；会话可继续；普通终端不被误中断 |
| 分栏尺寸 | 调整窗口尺寸，切换本地标签，再返回 Agent | Agent TUI 重绘正常，输出不串入其他终端；尺寸同步与焦点可恢复 |
| 重开与退出 | 关闭 Agent 分栏，再次打开，最后退出应用 | 关闭行为与界面承诺一致；不会意外启动重复 Agent；应用退出后无孤立 Agent/host 进程 |
| 上下文边界 | 在普通终端输出一段测试文本，再查看 Agent | 文档和界面不宣称自动共享未实现的终端上下文；实际共享行为必须有清晰入口 |

## SSH、SFTP、转发与串口入口

图形入口负责收集连接参数并在终端会话中启动系统客户端。
SFTP 验收针对交互式 SFTP 终端；图形文件浏览器不属于当前已实现功能。

| 用例 | 真实操作 | 通过标准 |
| --- | --- | --- |
| 新建 SSH 校验 | 提交空主机、无效端口、前导 `-` 的目标、包含换行或 shell 元字符的字段 | 无效值被拒绝或作为字面参数处理；不执行额外本地命令；错误指向具体字段 |
| SSH 正常连接 | 用测试主机新建 SSH 会话，处理首次主机密钥确认并认证 | 原生 OpenSSH 提示可见；未绕过主机密钥校验；连接后输入 `pwd` 得到远端目录 |
| SSH 失败 | 输入错误用户名、拒绝主机密钥或连接不可达端口 | 失败和退出状态可见；应用不崩溃；其他会话不受影响 |
| SFTP | 打开测试 SFTP 会话，执行 `pwd`、`ls`，上传下载一个临时文件，退出 | 命令交互正常；文件内容一致；没有把终端包装误称为图形文件管理器 |
| 本地转发 | 建立指向受控测试服务的本地转发，用本机客户端访问，再关闭会话 | 转发可用；关闭后监听端口释放；端口占用时显示失败 |
| 远程/动态转发 | 对实际提供的图形选项分别建立 `-R`、`-D` 测试连接 | 参数对应所选模式；监听/目标信息准确；失败可见；停止后资源释放 |
| 串口参数 | 选择测试设备、合法波特率，并尝试无效波特率或不存在的设备 | 参数校验或底层错误可见；无假连接状态；错误后可重试 |
| 串口收发 | 与回环或模拟设备双向发送测试文本，再断开/拔出设备 | 输入输出一致；断开可见；关闭会话后设备句柄释放 |
| 缺少客户端 | 在没有 OpenSSH 或 pyserial 的受控环境打开对应入口 | 明确说明缺失的程序及该功能不可用；本地终端与 Agent 仍可启动 |

## 打包、IPC 与生命周期回归

- 从打包应用启动 Agent，确认选择随应用提供的源码构建包；主程序、
  `codex-code-mode-host` 和所需资源都存在，不依赖开发目录的绝对路径。
- 将窗口快速打开/关闭、重复新建/关闭标签，检查重复 IPC 监听、会话数量与内存是否持续增长。
- renderer 只能经预加载桥访问明确的会话接口；IPC 对会话 ID、类型、尺寸与连接参数
  做校验，不能访问其他窗口拥有的会话或调用任意 Node API。
- 会话退出、renderer 销毁、窗口关闭与应用退出后，检查所有所属 PTY、Agent、
  辅助程序和 SSH 转发进程；不能只根据 UI 标签消失判定清理成功。
- 检查窗口导航与弹窗：不允许不可信远程页面获得终端控制能力。
