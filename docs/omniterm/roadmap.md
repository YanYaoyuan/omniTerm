# omniTerm 路线图

omniTerm 面向 macOS、Linux 和 Windows，结合 iTerm2 式终端体验、
MobaXterm 式远程连接工具与基于 Codex 的 Agent 模式。
当前主入口是桌面应用；CLI 作为可选入口保留。

桌面初版已实现。macOS arm64 的本机应用包已构建并打开窗口，真实 PTY 的
命令输入、尺寸、中断与关闭检查已通过；完整 GUI、Agent 与远程交互验收仍待完成。
下文的“已有实现”描述代码状态，不代表三平台已发布或所有真实设备场景已验证。

## 当前实现与后续方向

| 能力 | 已有实现 | 下一步 |
| --- | --- | --- |
| 本地终端 | Electron/React、xterm.js（WebGL）、node-pty、多标签、任意分屏、广播输入、命令面板、主题、搜索、复制粘贴、工作区布局恢复 | 三平台输入与性能验收、可自定义快捷键 |
| Agent | 终端旁的独立 Codex TUI，源码构建的主程序与 host 随本机应用打包；显式发送选中终端内容 | 结构化 app-server 界面与任务状态 |
| SSH | 图形连接表单、保存/编辑/删除配置、系统 OpenSSH 终端 | 配置导入、跳板机专用界面、重连体验 |
| 端口转发 | 图形配置本地/远程/动态模式，独立 SSH 会话 | 独立转发状态面板、健康检查与清理回归 |
| SFTP | 图形入口启动交互式系统 SFTP 客户端 | 文件浏览、传输队列、进度、取消和冲突处理 |
| 串口 | 设备与波特率表单、pyserial miniterm 终端 | 设备发现、更多连接参数、收发视图与日志 |
| 构建与发行 | 桌面构建/本机打包脚本、完整源码 Agent 包、三平台代码 CI 配置 | 原生运行验收、签名安装包、校验信息和自动更新 |

SSH/SFTP/串口继续使用本机外部工具。普通终端可在未配置模型账号时使用；
Agent 不会自动读取其他标签或获得远程执行权限。

## M0 · 开源基础与 CLI

**已有实现：** 独立仓库与品牌、Apache-2.0 和上游声明、贡献入口、
CLI 命令和依赖诊断，以及独立 CI。源码构建路径生成完整 Agent 包。

**持续验收：** 新贡献者能理解桌面与 CLI 的定位、构建引擎、运行开发入口，
并区分源码能力、外部依赖和未实现功能。CLI 参数与错误处理继续进行回归。

## M1 · 桌面初版验收

**已有实现：** Electron 主进程与受限 IPC、React 工作台、xterm.js 终端、
node-pty 会话管理、本地标签、搜索、复制粘贴、终端设置、连接配置与 Agent 分栏。

**待完成的验收：**

- 在三平台检查 `pwd`、Ctrl+C、中英文输入、复制粘贴和窗口/字号尺寸同步。
- 检查标签切换、关闭、进程退出和应用退出后的 PTY/子进程清理。
- 验证 Agent TUI 的真实键盘操作、认证、审批、任务执行与取消。
- 在对应平台的本机包中确认使用随包的源码 Agent 与辅助资源。
- 记录缺失依赖、界面错误与不可用功能，避免以构建成功代替运行验收。

具体用例与记录表见 [desktop-test-plan.md](desktop-test-plan.md)。
本机 PTY 测试直接操作 PTY；不能代替 GUI 键盘输入、输入法或 Agent TUI 的人工操作。

## M2 · 完整终端体验

- 已实现任意分屏、广播输入、命令面板与内置主题；待完成可配置快捷键和可访问性改进。
- 完善长输出、Unicode、输入法、滚屏和多会话性能。
- 已实现工作区布局恢复：只还原本地标签、分屏与目录，不重新执行命令、不自动重连远程会话；
  滚屏内容与远程会话恢复待评估。
- 提升关闭、崩溃和系统休眠后的状态一致性。

**验收：** 三平台完成真实 shell 与终端程序回归；性能、资源使用和
生命周期测试有可重复记录，不把某个平台的结果推广到其他平台。

## M3 · 结构化 Agent 工作区

当前分栏已经可运行 Codex TUI，下一阶段通过 app-server 适配器提供原生
任务界面、流式事件、工具调用、审批、取消和恢复。

- 用户明确选择要共享的终端输出、文件和上下文。
- 显示引擎、模型、目录和实际执行主机。
- 处理引擎退出、协议不兼容与会话恢复，避免重复执行操作。
- 为其他 Agent 引擎保留独立适配接口与权限语义。

**验收：** 完成“查看终端错误 → 共享选中上下文 → 审批操作 → 检查结果”，
并验证取消、重连与上下文边界。

## M4 · 远程与设备工作流

- SSH 配置导入、跳板机专用设置与更清晰的连接状态。
- 独立的转发管理面板、可用性判断和生命周期管理。
- SFTP 图形目录浏览、传输队列、取消、重试与覆盖确认。
- 串口设备发现、连接参数扩展、收发视图及可选日志。
- 明确远程 Agent 的部署/执行模型及权限边界。

**验收：** 使用受控服务与测试设备覆盖主机密钥变化、认证失败、端口占用、
断网、传输取消、设备拔出及远程任务取消。未具备测试环境的项目明确标记未执行。

## M5 · 跨平台发行

- 在 macOS、Linux、Windows 分别构建并验证匹配架构的完整应用包。
- 建立签名、公证、安装器、校验信息与升级路径。
- 验证配置迁移、依赖更新和上游 Codex 同步。
- 发行说明列出实际验证的平台、已知限制和未覆盖场景。

**验收：** 干净环境能够安装与运行，内置 Agent 不依赖开发机器路径；
自动化构建、原生运行、人工交互和远程设备测试各有记录。

详细模块边界见 [architecture.md](architecture.md)。
